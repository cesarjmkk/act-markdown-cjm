# Detalles Técnicos del Despliegue
En este documento se recogen las especificaciones del entorno de desarrollo y producción para este módulo.
## Configuración del Sistema
- **Sistema Operativo:** macOS 27.2  
- **Servidor Web:** Nginx 1.24+ o Apache HTTP Server 2.4+
- **Gestor de versiones:** Git 2.40+
---
## Buenas Prácticas de Mantenimiento
1. Mantener las rutas relativas en la documentación interna para garantizar portabilidad.
2. Comprobar que los enlaces externos utilicen HTTPS siempre que sea posible.
3. Versionar periódicamente los ficheros de configuración (`.conf`).
